## 💼 JobFinder

JobFinder is a LinkedIn-inspired front-end web application designed to simulate a modern job networking platform. It focuses on clean UI design, structured layout, and dynamic content rendering using a public API.

The project emphasizes front-end development skills, creating a realistic job platform experience using only HTML, CSS, and JavaScript.

## ✨ Features
The application includes:
- A **login page**
- A **home page** with a **3-column layout**
- Random users displayed using the **Random User API**

## 👤 Random User API 
- At least **10 users** are fetched
- Displays:
  - Profile picture
  - Full name
  - City
- Data is retrieved using the **Fetch API**
